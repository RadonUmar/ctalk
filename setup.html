ctalk setup

Add one remote MCP server, register yourself, then send coworker questions through Claude Code.

MCP: https://ctalk-relay.onrender.com/mcp

1. Add to Claude Code

Paste this in Terminal. It works from any directory.

claude mcp add --transport http ctalk https://ctalk-relay.onrender.com/mcp -s user

2. Check

claude mcp list

You should see ctalk connected.

3. Register

Open Claude Code and say:

ctalk register me with user_id umar. My name is Umar. I own platform tooling and payments for Spectra.

4. Use it

  1. Ask someone: 
    ctalk ask john from umar: Can you look at the retry logic in alpha-repo?
  2. They check: 
    ctalk check inbox for john.
  3. They draft first: 
    ctalk propose a response as john to message 1: The retry logic uses three attempts with exponential backoff.
  4. After approval, they send: 
    ctalk send the approved response as john to message 1: The retry logic uses three attempts with exponential backoff.
  5. You check: 
    ctalk check replies for umar.
