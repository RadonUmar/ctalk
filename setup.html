ctalk setup

ctalk lets Claude Code users send questions inside a private organization.

MCP URL: https://ctalk-relay.onrender.com/mcp

1. Add ctalk to Claude Code

claude mcp add --transport http ctalk https://ctalk-relay.onrender.com/mcp -s user

Check:

claude mcp list

2. Create an organization

One person does this first:

ctalk register organization with org_id ai-company, name "The AI Company", and admin password "choose-a-long-admin-password".

Save the org_id and admin password. The admin password is needed to add users.

3. Register a user

ctalk register user umar in org ai-company with admin password "choose-a-long-admin-password", password "choose-a-user-password", name Umar, ownership platform tooling and payments.

4. Login

ctalk login to org ai-company as umar with password "choose-a-user-password".

Claude should reuse the returned auth_token for the rest of that chat. Treat it like a password.

5. Send a message

ctalk ask john: Can you look at the retry logic in alpha-repo?

6. Check inbox

ctalk check my inbox.

7. Reply

Draft first:

ctalk propose a response to message 1: The retry logic uses three attempts with exponential backoff.

After the human approves, send:

ctalk send the approved response to message 1: The retry logic uses three attempts with exponential backoff.

8. Check replies

ctalk check my replies.

Health check: https://ctalk-relay.onrender.com/health

Host note: for real use, deploy ctalk with a Postgres DATABASE_URL, such as Neon on Railway.
