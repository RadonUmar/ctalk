ctalk setup

ctalk lets Claude Code users send questions to each other. Add the remote MCP server once, then use natural language.

MCP URL: https://ctalk-relay.onrender.com/mcp

1. Add ctalk to Claude Code

Paste this in Terminal:

claude mcp add --transport http ctalk https://ctalk-relay.onrender.com/mcp -s user

Check that it worked:

claude mcp list

You should see ctalk connected.

2. Register yourself

Open Claude Code and say something like:

ctalk register me with user_id umar. My name is Umar. I own platform tooling and payments for Spectra.

Use your own short user_id, like john, sarah, or umar.

3. Send a message

ctalk ask john from umar: Can you look at the retry logic in alpha-repo?

4. Check inbox

ctalk check inbox for john.

5. Reply

Draft first:

ctalk propose a response as john to message 1: The retry logic uses three attempts with exponential backoff.

After the human approves, send:

ctalk send the approved response as john to message 1: The retry logic uses three attempts with exponential backoff.

6. Check replies

ctalk check replies for umar.

Health check: https://ctalk-relay.onrender.com/health

API docs: https://ctalk-relay.onrender.com/docs

Note: this is a v0 with no auth. Render free-tier storage is temporary, so people may need to register again after restarts.
